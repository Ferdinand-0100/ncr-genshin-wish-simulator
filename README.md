# ncr-genshin-wish-simulator
Genshin Wish Simulator is part of No Code Rot (NCR)—a series of projects I'm building without generative AI to prove that I'm better than AI: a website that simulates the gacha/wishing experience in the popular role-playing game Genshin Impact.

## Background
So, funny thing: I absolutely hated web development. I don't even remember why anymore, just that it started back in senior high, where I took an extracurricular activity on computers and we were taught how to make a website. That's why I thought a good first step towards rebuilding my coding skill is to actually make the very first thing I hated about computer science.

## Installation
You can access the website directly from this repository's GitHub page which I will soon include here. In case you are weird enough to want to modify this project, you won't need to install any dependencies since this project only utilizes HTML + CSS + JavaScript (as of writing this README).
